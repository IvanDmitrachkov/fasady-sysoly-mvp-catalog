# Фасады Сысолы: сайт-каталог (MVP)

> **Статус: MVP.** Это рабочий прототип для показа заказчику и сбора обратной связи, а не готовый к запуску продукт. Что в нём настоящее, а что заглушка, описано в [mvp.md](mvp.md). Перед публикацией читайте раздел «Что нужно до боевого запуска».

## О проекте

Заказчик: производитель МДФ-фасадов «Фасады Сысолы» (Сыктывкар). Услуги: покраска, фасады в плёнке, производство, радиусные фасады, фрезеровка.

Цель сайта: каталог фасадов в современном дизайне с 3D-эффектами, чтобы посетитель мог покрутить фасад, сменить цвет и увидеть кухню целиком, а затем оставить заявку.

Исходный материал от заказчика: PDF-каталог `PDF_Katalog_fasadov_2026_v1.pdf` в корне репозитория. Из него взяты номенклатура, размеры, фото, схемы и контакты.

## Что умеет сайт сейчас

| Раздел | Адрес | Суть |
|---|---|---|
| Главная | `/` | Hero-баннер с фото кухни, «Кто мы», услуги, превью каталога, примерочная, «Почему мы», шаги заказа, заявка (без 3D) |
| Каталог | `/catalog` | 25 позиций из PDF, фильтр по типу |
| Карточка фасада | `/catalog/[slug]` | 3D-вьюер (для 7 фасадов), характеристики, схема, галерея, заявка |
| Калькулятор заказа | `/calculator` | Позиции с параметрами, расчёт цены (условный), заказ и выгрузка в Excel |
| Конструктор кухни | `/constructor` | Прямая кухня из модулей, фасады из каталога, список фасадов в заявку (прототип) |
| Примерочная кухни | `/kitchen` | Фото кухни, перекраска фасадов, акцентных колонн, столешницы и фартука |
| Приём заявок | `POST /api/lead.php` | PHP-скрипт: валидация и письмо на почту; пока `LEAD_TO` пуст, **никуда не отправляет** (демо) |

## Правило для тех, кто продолжает работу

Пока проект в статусе MVP, любые данные в нём считаются **предварительными**: размеры профилей приблизительные, тексты карточек написаны как заглушки, фото на сценах не лицензированы для публикации. Подробности в [mvp.md](mvp.md) и [data-and-assets.md](data-and-assets.md).
