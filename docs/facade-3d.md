# 3D-фасад

> **MVP.** Форма фасадов правильная, но размеры профилей **приблизительные** (сняты с картинок PDF). Для боевого запуска их нужно сверить с чертежами заказчика.

## Идея

Фасад МДФ это плита с фрезерованным рельефом. Поэтому 3D строится **кодом по профилю сечения**, а не загружается как готовая модель:

- не нужен Blender и 3D-художник;
- размеры можно менять ползунками без искажения рельефа (профиль остаётся в реальных миллиметрах);
- новую фрезеровку добавляют данными, а не моделированием;
- нет тяжёлых файлов: страница загружает только код.

## Профиль

Профиль описывается в `src/lib/profiles.ts`, размеры в миллиметрах. Три типа:

| Тип | Для чего | Как задаётся |
|---|---|---|
| `flat` | Гладкий фасад | Без параметров |
| `edge` | Рамочные фрезеровки (Степ, Баден, Кант, Премьер) | Точки `[d, depth]`: `d` — расстояние от края фасада, `depth` — глубина выборки от лицевой плоскости. Дальше последней точки глубина постоянна |
| `stripes` | Рейки и волны | `pitch` (шаг) и точки `[u, depth]`, где `u` в пределах шага. Профиль повторяется по ширине |

Для `edge` глубина в точке `(x, y)` берётся от расстояния до ближайшего края `d = min(x, W−x, y, H−y)`. Благодаря этому **косые стыки (45°) в углах рамки получаются сами**, без ручной сшивки.

## Построение геометрии

`src/lib/facadeGeometry.ts`, функция `buildFacadeGeometry(profile, width, height, thickness)`:

1. По профилю считаются узлы сетки вдоль осей: плотные у краёв, где рельеф, редкие в середине. Геометрия небольшая: сотни, а не сотни тысяч вершин.
2. Лицевая поверхность строится по сетке, диагональ каждой ячейки выбирается так, чтобы она шла вдоль косого стыка угла.
3. Добавляются торцы (идут по периметру) и тыльная сторона.
4. UV задаются в метрах, чтобы текстуры дерева были привязаны к реальным размерам.
5. Нормали считаются `toCreasedNormals`: резкие рёбра остаются резкими, а скругления (волна, лепнина) сглаживаются.

Геометрия центрируется в нуле, лицевая сторона смотрит в `+Z`.

## Материалы и свет

`src/components/viewer/FacadeViewer.tsx`:

- Материал `MeshPhysicalMaterial`. Матовое покрытие: `roughness 0.62`, без лака. Глянцевое: `roughness 0.12`, `clearcoat 1`.
- Свет это студийное окружение из `Lightformer` (софтбоксы), без загрузки внешних HDRI. Окружение рендерится один раз.
- Для «дерева» создаётся процедурная текстура на `canvas` (вертикальные волокна) поверх базового цвета.
- Рендер по требованию (`frameloop="demand"`), `dpr` ограничен 2. Масштаб фасада нормализован, чтобы большая сторона всегда занимала одну долю кадра.
- Управление: `OrbitControls` без масштабирования и сдвига, ограничены углы. Масштабирование колесом отключено специально, чтобы не перехватывать прокрутку страницы.

`FacadeConfigurator.tsx` это интерфейс вокруг вьюера: цвета, покрытие, ползунки размеров. 3D подгружается через `next/dynamic` без SSR.

## Как добавить фрезеровку

1. Добавьте профиль в `profiles` (`src/lib/profiles.ts`). Берите размеры с чертежа сечения.
2. В `src/lib/catalog.ts` у нужной позиции укажите `profile: "<ключ>"`.
3. Откройте `/catalog/<slug>` и проверьте: углы, глубину, поведение на разных размерах.

## Что 3D пока не умеет

- Интегрированные ручки (8 вариантов): ручка вырезается не по всему периметру, а по одному краю или по центру, нужен другой тип генератора.
- Радиусные фасады: нужна геометрия изгиба по радиусу.
- Столешницы: профиль кромки, протянутый по длине.
- «Лес» (ёлочка): узор из косых канавок.
- Фрезеровки без размеров в MVP: Волна 2, Каприччо, Брилон, Альберо, Выборка, Выборка с конусом.
- Реальная плёнка ПВХ: нужны текстуры.
