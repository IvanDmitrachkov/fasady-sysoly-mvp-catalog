# Разработка

> **MVP.** Автотестов нет. Минимальный набор проверок: типы, линтер, сборка и просмотр в браузере.

## Запуск

```bash
npm install
npm run dev
```

По умолчанию сайт открывается на `http://localhost:3000`. Если порт занят, Next.js сообщит об этом или (в превью Claude) предложит порт 3001. Один проект может держать только один `next dev` одновременно.

## Проверки

```bash
npx tsc --noEmit    # типы
npm run lint        # eslint
npm run build       # продакшен-сборка
```

Глобальные типы `PageProps` и `LayoutProps` создаются при запуске `next dev` или командой `npx next typegen`. Если `tsc` ругается на них, выполните `npx next typegen`.

Перед сдачей изменений: проверить типы, линтер и сборку, затем руками пройти `/`, `/catalog`, `/catalog/<slug>` (с 3D и без), `/kitchen` на десктопе и в мобильном размере.

## Деплой

Статический экспорт (`output: "export"`) убран, сайт собирается как обычное Next.js-приложение и запускается через Node.js:

```bash
npm run build
npm run start
```

Выбор нового хостинга ещё не сделан. Автодеплой GitHub Actions на Beget отключён (`.github/workflows/deploy.yml`, только ручной запуск). Форма заявок `public/api/lead.php` рассчитана на PHP-хостинг и на Node-хостинге работать не будет, её нужно заменить (например, на route handler). Почта в `LEAD_TO` пока не указана, форма работает в демо-режиме.

## Подготовка масок для примерочной

Нужен Python 3 и библиотеки:

```bash
pip install opencv-python-headless numpy pillow
python3 tools/make_masks.py tools/scenes/<id>.json
```

Подробности: [kitchen-tryon.md](kitchen-tryon.md).

## Извлечение картинок из PDF

В PDF текст закодирован нестандартно, а изображения имеют отдельные маски прозрачности. Если нужно достать их заново, используйте PyMuPDF и учитывайте маску (`smask`), иначе прозрачные области получатся чёрными. Также в PDF есть серые изображения-«тени» под фотографиями, их нужно отфильтровывать. Уже извлечённые файлы лежат в `public/pdf`.

## Подводные камни

- **Next.js 16 отличается от привычных версий.** Читайте `node_modules/next/dist/docs/` перед правками роутинга, кэширования, загрузки данных (подробнее в `AGENTS.md`). В `next.config.ts` статический экспорт убран; `cacheComponents` и `partialPrefetching` пока оставлены отключёнными.
- **`ssr: false` в `next/dynamic`** разрешён только в клиентских компонентах.
- **`turbopack.root`** задан в `next.config.ts`, потому что в домашней папке пользователя лежит посторонний `package-lock.json`, и без этого Next выбирает неверный корень.
- **Размеры сцен** в `src/lib/scenes.ts` должны совпадать с реальными размерами `base.jpg` (после увеличения), иначе канвас и фото не совпадут.
- **WebGL на iOS Safari:** при нехватке памяти возможна потеря контекста. Держите на странице один 3D-канвас и не размножайте их в карточках каталога.
- **Не меняйте блок между маркерами `nextjs-agent-rules` в `AGENTS.md`:** его пересоздаёт `next dev`.
- **Порты:** если на 3000 открывается чужое приложение, проверьте, какой процесс его занимает, а не убивайте чужой процесс.
