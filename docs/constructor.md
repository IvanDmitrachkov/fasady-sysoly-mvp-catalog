# Конструктор кухни

Страница `/constructor`: пользователь собирает **прямую** кухню из типовых модулей, выбирает фрезеровку и цвет фасадов и получает список фасадов с размерами для заявки. Это прототип: габариты модулей условные, цен нет.

## Что умеет

- Длина стены 1800–4800 мм (шаг 100). Показывается занятая и свободная ширина; при переполнении выводится предупреждение.
- Три типа модулей: тумба с дверцами, тумба с ящиками (три ящика), пенал. Ширины: 300–900 мм из заданных наборов. У тумб можно включить навесной шкаф сверху.
- Общий фасад всей кухни (фрезеровка из каталога, где есть 3D, цвет, матовое или глянцевое покрытие) и своё оформление для выбранного модуля.
- Модули выбираются кликом в 3D или в списке; можно сдвинуть влево или вправо, сменить тип и ширину, удалить.
- Освещение: переключатель «День» и «Вечер». День: направленный свет с мягкими тенями от шкафов на стене и полу. Вечер: приглушённый тёплый свет и LED-подсветка под навесными шкафами.
- Таблица фасадов (одинаковые объединены): название, цвет, размер, количество. Кнопка «Заказать» подставляет сводку в форму заявки (поле «Что нужно» и комментарий).
- Проект сохраняется в `localStorage` браузера (ключ `fasady-kitchen-v1`).

## Устройство

| Файл | Роль |
|---|---|
| `src/lib/kitchen.ts` | Модель: типы, размеры (`dims`), расчёт раскладки `layoutProject`, сводка `facadeSummary`, проект по умолчанию |
| `src/components/constructor/KitchenViewer.tsx` | 3D-сцена R3F: корпуса, столешница, фасады (геометрия из `buildFacadeGeometry`), выделение, камера |
| `src/components/constructor/KitchenConstructor.tsx` | Интерфейс и состояние |
| `src/components/constructor/ConstructorClient.tsx` | Загрузка конструктора через `next/dynamic` с `ssr: false` |
| `src/lib/grainTexture.ts` | Текстура дерева, общая с вьюером фасада |

Единицы: в логике и сцене всё в миллиметрах; группа сцены масштабируется на 0,001. Фасады ставятся на лицевую плоскость корпуса, зазор между ними 3 мм.

## Ограничения и допущения

- **Размеры условные:** плинтус 100, тумба до 820, столешница 38, навесной шкаф 1400–2200, пенал до 2200, глубины 560/320/600. Делёж высот фасадов у пенала (1200 + 900) и ящиков (290, 210, 220) выбран произвольно. До запуска нужно сверить с заказчиком.
- Только прямая раскладка в один ряд, угла и острова нет. Нет техники, ручек, цоколя с регулировкой, фасадов для встройки.
- Нет цен и расчёта стоимости.
- Свободное место справа остаётся пустым (доборных элементов нет).
- Мобильная версия и перетаскивание на сенсорном экране не проверялись; модули меняются кнопками, а не перетаскиванием.
- Тени считаются картой теней (2048 px), на слабых телефонах может понадобиться снизить качество; LED-подсветка это точечные источники по одному на шкаф.
- Колесо мыши камеру не масштабирует (чтобы не перехватывать прокрутку страницы).
