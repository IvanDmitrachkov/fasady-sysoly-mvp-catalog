# Архитектура

> **MVP.** Структура рассчитана на быструю итерацию. Каталог лежит в коде, а не в CMS.

## Стек

| Слой | Технология |
|---|---|
| Фреймворк | Next.js 16 (App Router, Turbopack, Node-сервер), React 19 |
| Язык | TypeScript |
| Стили | Tailwind CSS 4 + токены в `src/app/globals.css` |
| 3D | three.js 0.187, `@react-three/fiber` 9, `@react-three/drei` 10 |
| Шрифт | Montserrat (латиница и кириллица) через `next/font/google` |
| Инструменты разметки | Python 3 + OpenCV (только для подготовки масок, в рантайме не нужен) |

В этой версии Next.js есть отличия от более ранних. Перед правкой роутинга и кэширования читайте документацию из `node_modules/next/dist/docs/` (на это указывает `AGENTS.md`).

## Маршруты и рендеринг

- `/`, `/catalog`, `/kitchen`, `/constructor`, `/calculator` статические.
- `/catalog/[slug]` статически генерируется для всех 25 позиций (`generateStaticParams`).
- Сайт собирается в статику (`out/`), серверной части нет. Заявки принимает `public/api/lead.php` (PHP на хостинге).
- 3D-вьюер и примерочная это клиентские компоненты. 3D загружается через `next/dynamic` с `ssr: false` (разрешено только внутри клиентского компонента), а у примерочной до загрузки видна обычная картинка, поэтому SEO и первая отрисовка не страдают.

## Данные

Всё лежит в `src/lib/`:

- `catalog.ts`: массив `facades` (slug, название, категория, ссылка на 3D-профиль, описание, фото, схема), категории, общие габариты (`limits`), контакты, преимущества.
- `profiles.ts`: профили сечений. Ключи совпадают с `ProfileId`, на которые ссылается `catalog.ts`.
- `palette.ts`: 27 образцов (13 RAL, 11 NCS, 3 «дерева»), служебный «Подбор» и покрытия «матовый» и «глянцевый». Группа Color System объявлена, образцов нет (ждём каталог от производства).
- `components/ColorPicker.tsx`: общий выбор цвета (вкладки каталогов, поиск по коду, плитки с кодом, блик у глянца, вкладка «Подбор» с текстом). Рассчитан на сотни образцов: при более чем 24 в группе появляются фильтр по оттенку (семейство считается из HEX автоматически), счётчик, блок «Недавние» (`localStorage`) и прокрутка списка. Чтобы добавить цвета, достаточно дописать их в `palette.ts` и `FinishToggle`. Используется в карточке фасада, конструкторе и примерочной.
- `scenes.ts`: сцены примерочной и палитры столешниц и фартуков.

Подробнее: [facade-3d.md](facade-3d.md) и [kitchen-tryon.md](kitchen-tryon.md).

## Дизайн-система

Взята из PDF и усилена:

- Токены (`globals.css`): `--paper` белый, `--mist` светлый серый, `--ink` почти чёрный, `--graphite` графит, `--night` тёмный фон для 3D и подвала.
- Типографика: Montserrat, очень жирные крупные заголовки с `clamp()`, мелкие подписи капсом с разрядкой.
- Мотив: диагональный срез (`.cut-corner`, `.cut-top`) из обложки каталога. В текущем MVP классы объявлены, но нигде не применены. Это задел под доработку дизайна.
- Цвет приносят сами фасады, поэтому интерфейс монохромный.
- Доступность: радиогруппы для выбора цвета и покрытия с `aria-label`, `prefers-reduced-motion` отключает анимации.

## Заявки

`LeadForm` отправляет JSON в `/api/lead.php` ([public/api/lead.php](../public/api/lead.php)). Скрипт проверяет имя и телефон (минимум 10 цифр), обрезает длинные значения, отбрасывает запросы с заполненным скрытым полем `website` и отправляет письмо через `mail()`. Пока константа `LEAD_TO` пуста, это демо-режим: заявка проверяется, но **никуда не уходит**, а форма всё равно показывает «Заявка отправлена». Перед реальным запуском `LEAD_TO` нужно заполнить. Под `next dev` PHP не работает, форма там вернёт ошибку.
